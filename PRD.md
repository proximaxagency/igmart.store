# PRD.md — IGMart.store Product Requirements Document

## Executive Summary
IGMart.store is a multi-vendor digital gaming marketplace operating system built on Next.js 16, React 19, Clerk, Convex, and Vercel. It supports high-velocity trading of Game Accounts, Items, Currency, Keys, Top-Ups, and Boosting Services with escrow holds, automated inventory vaults, real-time customer support chat, and a full Operations Admin Control Center.

## Core Pillars
1. **Buyer Marketplace**: Dynamic category filters, instant checkout, real-time order chat, and buyer protection warranty.
2. **Seller Hub**: KYC verification stepper, inventory vault for 100% instant automated delivery, wallet ledger, multi-channel payout withdrawals, and seller offer scoring.
3. **Operations Admin Control Center**: Command Center metrics, seller KYC application approvals, payout release queue, listing moderation, dispute arbitration engine, fraud & risk operations, and immutable audit logs.
4. **Trust & Security Architecture**: Multi-role RBAC, server-validated Clerk identity resolution, immutable ledger transactions, and automated velocity risk signals.
